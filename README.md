📊 **Real-Time Stock Data Analyzer**


A full-stack MERN application that fetches real-time stock data from Yahoo Finance, calculates technical indicators (SMA, EMA, RSI, MACD), and provides actionable insights like overbought/oversold conditions and trend signals.

Perfect for technical analysis , trading strategy testing , and learning full-stack development with Python integration .



🔍 Features

✅ Built using MERN Stack + Python for calculations

✅ Technical Indicators Implemented:

SMA (Simple Moving Average)

Identifies long-term trends

EMA (Exponential Moving Average)
More responsive to price changes

RSI (Relative Strength Index)
Detects overbought (>70) and oversold (<30) zones

MACD (Moving Average Convergence Divergence)
Tracks momentum and trend changes
